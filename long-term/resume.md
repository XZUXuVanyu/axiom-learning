## Authority and conflicts

Explicit current learner instructions govern the task. Standing learning policy lives in learning-rules.md; goals and design live in their named files; current state lives only in progress.md plus linked evidence. Root legacy policy files are pointers. Preserve disagreements and resolve them from evidence instead of silently marking completion.

An ordinary solution request is not a deliberate policy revision. Record deliberate changes with date, reason, and affected documents.

Remote commits are visible only after fetching or reading them. Local-only/unpushed changes are invisible to the daily checker. Pull remote documentation before continuing local work; do not overwrite uncommitted changes.
